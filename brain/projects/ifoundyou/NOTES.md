# iFoundYou / Dommedag prototype

iFoundYou is the repository name; the README and Web interface also use Dommedag. The public
name is unresolved, so this record keeps both names and labels the work as a prototype.

## Verified status and contribution

The public repository contains an experimental location, community, and off-grid communication
prototype. It has no recorded public release or canonical live demo. Carlos maintains the public
repository and is its documented GitHub contributor; this does not establish sole authorship or
ownership of every research document or asset.

## What the repository demonstrates

- a Vite, React, and TypeScript Web application using MapLibre and browser geolocation;
- Supabase Auth, Postgres/PostGIS, Realtime behavior, and row-level policies;
- friend, discovery, chat, notification, blocking/reporting, and community-alert surfaces;
- PWA and offline-caching configuration;
- Meshtastic browser transports and native iOS Multipeer / Android Wi-Fi Direct experiments;
- an optional privileged local networking helper that remains unsuitable for portfolio demo or
  recommendation without dedicated security work.

## Publication boundary

This portfolio record does not claim production reliability, explicit opt-in location sharing,
privacy-first operation, emergency-service integration, verified alerts, field-tested offline
delivery, or life-safety suitability. Location consent, retention, deletion, coarse-location
behavior, moderation, and security remain unresolved work.

No repository image or location/contact data is copied into the portfolio. The repository has no
detected license, and no project media has documented portfolio reuse permission.
