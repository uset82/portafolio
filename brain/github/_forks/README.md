# Fork records

The automatic GitHub sync excludes forks. A fork may be represented here only by a
hand-authored record that explains Carlos's contribution without claiming sole authorship.

Every fork record must contain a non-empty `contributionNotes` field before it can set
`public: true`. The sync reserves this directory and never creates, rewrites, or deletes its
contents.
