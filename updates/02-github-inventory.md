## 6. Sync script rules (`B.4` acceptance criteria)

1. Fetch only `owner === "uset82"`, `fork === false`, `size >= 50 KB`.
2. Pull: description, topics, languages, license SPDX, homepage, default branch, `pushed_at`,
   README, and any `AGENTS.md` / `agents.md` / `docs/**` / `*_DIARY.md` present.
3. **Never** fetch stars, forks, watchers, or issue counts.
4. Write only into `brain/github/` — never touch an authored folder.
5. Stamp every file with `checkedOn`.
6. Forks land in `brain/github/_forks/` with a mandatory `contributionNotes` field that must
   be filled by hand before the repo may be marked `public: true`.
7. Re-running on unchanged upstream produces an empty diff.
